2. ==> Operators (Amaliyat Ke Nishan)

1. ==> Arithmetic Operators (Hisab Ke Operators)
Ye mathematical calculations ke liye use hote hain. Addition ke liye +, subtraction ke liye -, multiplication ke liye *, division ke liye /, aur remainder nikalne ke liye modulo % operator use hota hai. Increment ++ variable ki value 1 se barhata hai aur decrement -- 1 se ghatata hai.

2. ==> Assignment Operators (Value Dene Ke Operators)
Basic assignment operator = hai jo right side ki value ko left side ke variable mein store karta hai. Shorthand operators bhi hain jaise +=, -=, *=, jo pehle operation karte hain phir assign karte hain.


3. ==>  Comparison Operators (Muqabla Ke Operators)
Ye do values ko compare karte hain aur boolean result dete hain. Equal to == sirf value check karta hai jabke strict equal === value aur type dono check karta hai. Not equal != aur strict not equal !== bhi hain. Greater than >, less than <, greater than or equal to >=, aur less than or equal to <= bhi available hain.


4. ==>  Logical Operators (Mantiq Ke Operators)
AND operator && tab true deta hai jab dono conditions true hon. OR operator || tab true deta hai jab koi ek condition true ho. NOT operator ! condition ko reverse kar deta hai.

5. ==>  Ternary Operator
Ye if-else ka short form hai. Syntax hai condition ? value_if_true : value_if_false. Ye ek line mein simple conditions handle karne ke liye bohot useful hai.


1. ==> Type Operators
typeof operator variable ki data type batata hai. instanceof operator check karta hai ke object kisi specific constructor ka instance hai ya nahi.

2. ==>  Truthy aur Falsy Values
JavaScript mein kuch values automatically false consider hoti hain jaise 0, "" (empty string), null, undefined, NaN, aur false. Baki sab values truthy hoti hain. Ye concept conditions mein bohot important hai kyunke direct boolean value ke ilawa bhi values ko test kar sakte hain.
