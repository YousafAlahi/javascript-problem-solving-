

`1. Data Types (Data Ki Qismain)`
JavaScript mein do tarah ki data types hoti hain:

`11. ==> Primitive Data Types`
Ye wo data types hain jo direct value store karti hain:

`1. ==>  Number` - Ye tamam numbers ko represent karta hai, chahe wo integers hon ya decimals.JavaScript mein integers aur floats mein koi farq nahi hota.

`2. ==> String `- Ye text data ko store karta hai. Strings ko quotes mein likha jata hai, jaise "Hello", 'Salam', ya backticks mein \Kia hal hai``. Strings mein letters, numbers, aur symbols ho sakte hain.

`3. ==> Boolean ` - Ye sirf do values rakhta hai, ya to true ya false. Ye conditional statements aur comparisons mein bohot istemal hota hai.

`4. ==> Undefined ` - Jab koi variable declare ho lekin uski value assign na ki gayi ho, to wo undefined hoti hai.

`5. ==> Null` - Ye intentionally empty value ko represent karta hai. Jab aap explicitly kehna chahte hain ke variable mein kuch nahi hai.

`6. ==> Symbol` - Ye unique identifiers banane ke liye use hota hai. Mostly advanced programming mein use hota hai.

`7. ==> BigInt` - Bohot badi integers ke liye use hota hai jo normal Number type handle nahi kar sakta.

`22. ==> Non-Primitive (Reference) Data Types`
Ye wo types hain jo references store karti hain:

`1. ==> Object `- Ye key-value pairs ka collection hota hai. Objects complex data structures banane ke liye use hote hain.

`2. ==> Array `- Ye ordered list hota hai jisme multiple values ek saath store kar sakte hain.

`3. ==> Function` - Ye bhi ek object type hai jo executable code ko represent karta hai.
